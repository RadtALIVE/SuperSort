SuperSort

Automatically labels empty, compatible shelf slots for unassigned products. Your restockers still do all the actual work.

Download latest release View on GitHub

The restocking isn't the tedious part.

Supermarket Simulator's restockers are good at their job — once a shelf slot is labeled for a product, they'll find it in storage or off the delivery truck and carry it over themselves. No help needed.

The tedious part is clicking through every empty slot yourself, one at a time, before any of that can even start.

SuperSort skips that one click. Everything downstream stays exactly as it was.

✓Sourcing stock — unchanged
✓Storage vs. delivery priority — unchanged
✓Carrying the box — unchanged
✓Stocking the shelf — unchanged

What it does

Five things, nothing more.

Automatic labeling

Scans for unassigned products and labels a compatible empty slot on a configurable interval.

Real compatibility checks

Reuses the game's own slot-compatibility logic instead of guessing which products belong where.

Duplicate-safe

Never assigns a product that already has a pending or active slot, never overwrites an existing label.

Assignment only

Doesn't spawn, move, or place a single product. That stays entirely up to the game's restocker AI.

F6 toggle

Off by default. Press F6 to enable or pause anytime — existing labels are never undone.

Installation

Install BepInEx

Get the IL2CPP build of BepInEx for Supermarket Simulator, if you haven't already.

Download SuperSort.dll

Grab it from the latest release.

Copy it into your plugins folder

Supermarket Simulator\BepInEx\plugins\SuperSort.dll

Launch and press F6

Load a save, press F6 in-game to enable SuperSort. Press it again anytime to pause.

⚠ Please back up your save

SuperSort is currently in BETA. It writes label/assignment state to display slots at runtime, and while it's designed to avoid touching anything else, it hasn't been tested across the full range of saves, shelf types, and game versions yet. A save backup means you can always roll back if something looks off, with zero risk to your progress.
